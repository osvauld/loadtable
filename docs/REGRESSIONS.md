# `tasks` regression catalogue (from `dev-macos`, 168 commits, ~660 tests)

Every row is a behaviour the rewrite must pin with a named test. `source` gives the
commit that fixed or pinned it and/or the old test function (file stem in brackets
where the name is ambiguous). Platform: `any` = Unix-portable contract, `linux` =
depends on /proc, PSI, /proc/locks or fdinfo, `macos` = native macOS path.

Sources read: `git log dev-macos` (all bodies) and every `#[test]` name under `src/`,
`crates/` and `tests/` on `dev-macos`. Rows merge tests that pin the same behaviour.

## Not to carry over (compatibility shims)

- **Legacy ledger migration** (`execution.rs` `legacy_ledger_migration_does_not_approve_backlog`): the new ledger starts with its own schema. If a migration exists at all, keep only its invariant: an imported backlog is never auto-approved.
- **`ui_legacy.rs`**: the temporary adapter that builds a partial snapshot from the old listing when `tasks status --json` is missing, with its `proc_parsers`, plus the `ui_source` retry of `status --json` against older binaries.
- **"Older daemon answers `unknown variant`" fallbacks**: `Job(id)`→`List`, `Recent(n)`/`list_active`→`List`, `Peers`, `stop-worker`/`drain`/`prioritize` "daemon predates ..." messages, the peer's "its tasks predates log search", the health "daemon predates health monitoring" note, and `tests/peer_protocol.rs` (old/new client compatibility). Version the protocol once and refuse mismatches.
- **Old-record defaults**: "old records mean default" for thresholds, `max_cargo_jobs`, run-CPU threshold, and `backfill_uses_old_rows_without_metrics...`/`never_rewrites_pre_metrics_history`.
- **Lock-name and inode compatibility with legacy Python clients**: the historical `/tmp/claude-$EUID` default, `rust_lock_excludes_python...`, `lease_survives_python_subprocess_boundary...`, "legacy/external client" labels, `legacy-python` holder parsing, `offload_agent.py`/`worker_source.py` prune and checkout-id parity tests. Keep these only while legacy clients still run beside the new daemon.
- **`--run` offloads and the `cost=cpu_simulation` legacy label** (`run_slot_offloads_stay_valid`): use the offload class only.
- **Embedded-layout self-suite default** (`self_suite_default_source_matches_only_the_embedded_layout`, `CHECKOUT/tools/task-manager`) and the Tinline catalog/adapters, `TASK_MANAGER_STATE_DIR` `tinline-task-manager-native` path.
- **`phone`/`emulator` client-side aliases kept "so older daemons are unchanged"**: keep the aliases if wanted, but drop the "daemon accepts only canonical strings for old daemons" reasoning.
- **SSH `tasks-offload` / `status-watch-ssh` / sidecar reconcile path** (`only_interrupted_ssh_offloads_are_candidates`): retired in favour of the iroh peer link (per the project's iroh-then-MCP direction). Keep the invariant (R-173: never mark an unknown remote half as success) for forwards.
- **Historical text pins**: `default_cargo_jobs_cap_rejects_three_with_the_historical_text`, `historical_identity_json_is_unchanged`, `thresholds_default_exactly_to_the_previous_constants`. Keep the values, not the exact wording.
- **`contracts.rs` `only_queued_jobs_can_be_cancelled_in_control_plane_milestone`**: a milestone restriction that running-job cancel supersedes.
