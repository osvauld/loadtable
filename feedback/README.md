# Agent trial feedback

Create a NEW uniquely named `<agent>-<job-id>-<topic>.md` using TEMPLATE.md after
meaningful use in each agent session, and summarize it in your task report.
Use `no-job` when submission itself is blocked. Never edit/append another agent's
report. If a name exists, choose a new suffix. No issues observed is valid;
identify what was actually exercised. Suggestions should include acceptance tests.

These are reviewable, non-secret source files. Keep full logs/state outside Git.
Do not stage/commit/push without permission. See ../TRIAL.md for the full policy.
